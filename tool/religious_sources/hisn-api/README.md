# مصدر الأذكار اليومية

الملفات JSON ردود أصلية محفوظة من [واجهة حصن المسلم العربية الرسمية](https://www.hisnmuslim.com/api/ar/husn_ar.json): 132 بابًا و267 ذكرًا وتعليمًا، بمعرّفات المصدر وترتيبه وحقل REPEAT وروابط التسجيل المعلنة. manifest.json يحفظ رابط كل ملف وSHA-256 ووقت الجلب. الـJSON الأصلي يحتوي فواصل أسطر داخل بعض السلاسل؛ يُقرأ strict=False دون تعديل الأرشيف.

التحديث الصريح: `python tool/fetch_adhkar_sources.py --refresh`. تشغيل الأمر بدونه يتحقق من الأرشيف دون شبكة. البناء: `python tool/build_adhkar_catalog.py` يكتب Flutter وحده. تحديث نسخة الباك يحتاج `--backend-root C:\laragon\www\haq-foundation` صريحًا. لا استخدام لمسار F أو G.

المولد ينشئ14 مجموعة يومية ويحتفظ بالأبواب132. مجموعتا الصباح والمساء تستعملان نص الباب27 كما ورد، بما فيه تعليمات الصيغتين؛ يستبعد النص المصرّح أنه خاص بالصباح من المساء، والخاص بالمساء من الصباح. لا توليد لصيغ أذكار جديدة ولا استنباط لعدد من لقطة تصميم. معرّف haq_content_id يربط الباب بمحتوى حصن المسلم الموجود في حق، دون تغيير محفوظاته.

مراجعة الأعداد: `python tool/audit_adhkar_counts.py` يعرض اختلافات REPEAT مع عبارات التكرار الصريحة. صُحّحت ثلاثة حقول إلى ما يقوله النص نفسه:83→7،130→3،148→7. السجل114 تعليمات مركبة للكابوس، وفي داخله خطوات تتكرر ثلاثًا؛ يبقى بطاقة تعليمات واحدة ولا يُحوّل إلى تكرار كل التعليمات ثلاث مرات. كذلك تبقى التعليمات المركبة الأخرى في النص. ملف الأذكار الناتج يسجّل التصحيحات وأدلتها؛ الأرشيف الخام لم يتغير.

التسجيل153 لا يحمل اسم ملف في المصدر (`/.mp3`)؛ يبقى غير متاح ولا يُختلق له رابط. وجود رابط التسجيل في المصدر لا يثبت تشغيله على جهاز؛ مشغل حق يتحقق من التحميل ويعرض الفشل عند عدم الإتاحة.

النص القرآني داخل الأقواس يُستبدل بنص حق المعتمد من Tanzil، وفق ربط صريح راجعناه بين رقم سجل المصدر ومفاتيح الآيات. تبقى الشواهد الجزئية أجزاء حرفية من تلك الآيات، وتُحفظ مفاتيحها والنص المستعمل للتحقق في التطبيق والباك. المقارنة الإملائية مجرد فحص للربط المحدد، ولا تختار آية أو تكتب نصًا دينيًا. ترخيص ومصدر نص القرآن محفوظان في الكتالوج الناتج أيضًا.
