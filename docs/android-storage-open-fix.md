# P17 — إصلاح فتح الأذكار وتهيئة التذكيرات على Android

أُعيد ظهور خطأ فتح أذكار الصباح في النسخة الموجودة على هاتف المستخدم، دون بناء أو تثبيت أو Run. سجل العملية أظهر DatabaseException عند `PRAGMA busy_timeout = 5000`: واجهة Android SQLiteStatement.execute ترفض الأوامر التي ترجع صفوفًا وتطلب query/rawQuery. أذونات الموقع والإشعارات والتنبيه الدقيق كانت مفعلة؛ سبب هذا الفشل ليس نقص الإذن.

كان ReligiousActivityStore يستدعي execute لهذا الـPRAGMA. الأذكار وتهيئة ReminderController يفتحان المخزن نفسه، ولذلك عطّل الفشل المسارين معًا. أصبح الاستدعاء rawQuery؛ لا تغيير إصدار مخطط أو حذف/إعادة إنشاء ملف أو ترحيل خادمي. بيانات الحساب والأحداث ومعرّف الجهاز تُحفظ.

اختبار activity_android_channel_test يستخدم عميل sqflite الفعلي مع قناة أصلية محاكية ترفض execute للأمر الذي رفضه الهاتف، ويثبت فتح قاعدة قائمة دون تصفيرها. اختبارات المخزن والجلسات والتذكيرات تكمل فحص العمليات بقاعدة SQLite الذاكرية. إثبات السبب من الهاتف لا يعني أن نسخة الهاتف تحمل الإصلاح؛ يلزم تحديث مصدرها عبر جلسة تطوير متاحة أو بناء لاحق من المستخدم، دون مخالفة طلبه الحالي بعدم Run/APK.
