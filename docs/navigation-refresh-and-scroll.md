# التنقل والتحديث وسلاسة القوائم — 29 أكتوبر 2026

طلب المستخدم فحص تعدد الشريط السفلي والضغط المكرر والرجوع، وإضافة السحب للتحديث وتحسين التمرير.

- الشاشة الرئيسية تملك شريط التنقل الوحيد بمفتاح ثابت. صفحات المحتوى تستعمل الشريط نفسه، بدل تبديله بالشريط الخاص بالمحتوى الديني. صفحات الخدمات المفتوحة فوق الجذر وقارئ القرآن الكامل لا تضيف شريطًا ثانيًا.
- إعادة اختيار القرآن أو الأذكار تعيد القسم لبدايته، واختيار «المزيد» من داخله يغلق قسم المحتوى إلى دليل الخدمات. الانتقال بين تبويبين مختلفين يبقي مكدس القسم السابق محفوظًا. مداخل الأدعية والمحفوظات تفتح المحتوى المطلوب مباشرة.
- فتح الخدمة نفسها أو صفحة القرآن أو المحتوى نفسه بسرعة لا يضيف نسختين إلى المكدس. يزول الحجز عند إغلاق الصفحة، فيمكن فتحها مرة أخرى. تهيئة قارئ الأذكار المتأخرة لا تفتح صفحة في تبويب غادره المستخدم.
- مؤشر تحديث واحد فوق الملاحين يستجيب للسحب العمودي من أعلى الصفحة، بما فيها القوائم القصيرة. وحدات الرسائل والمساعد والمكتبة تحتفظ باستدعاء تحديث بياناتها الفعلي عبر منطقة تحديث؛ لا تتداخل مؤشرات عدة. بقية الصفحات تحفظ الكتابات أولًا، تعيد قراءة التفضيلات وحساب الصلاة وحالة التذكيرات ومزامنة النشاط، دون إنشاء إنجازات أو محو موضع القراءة.
- التمرير الأفقي للقارئ وحقول الإدخال لا تشغّل التحديث. لا يُضاف تمرير عمودي إلى الخرائط أو الجلسات الثابتة ولا يُسرق إيماؤها. السلوك العمودي موحّد بلا وهج أو تمديد إضافي يتنافس مع مؤشر التحديث.
- دليل الخدمات وقوائم المحتوى والأسماء الحسنى أصبحت SliverList/SliverGrid كسولة؛ لا تُبنى جميع البطاقات والصور دفعة واحدة. أُبقيت مفاتيح PageStorage والبحث والترتيب وأبعاد البطاقات.

فحوصات `app_refresh_test` تغطي مؤشرًا واحدًا، تحديث مصدر الصفحة، رفض تكرار طلب جارٍ، القوائم القصيرة وعدم تحديث القارئ الأفقي. `navigation_test` يغطي التبويبات الخمسة، إعادة الاختيار، الضغط المكرر، ضغطة رجوع واحدة، حفظ مكدس التبويب غير النشط، كل مداخل المحتوى، البحث والتمرير في الفاتح والداكن وعرض320px. بعد التحميل الكسول أصبحت الاختبارات تبحث أو تمرر للوصول إلى عنصر لم يُبنَ بعد، بدل افتراض وجود كامل القائمة في الشجرة.
