# P12 — المساعد والباكج — تنفيذ محلي

قرار المستخدم: تطوير خدمة فعلية مدفوعة،20$ سقف شهري لتشغيل المساعد،5$ للباكج وتقدير1000 مستخدم. ثم طلب تأجيل المفاتيح وفتح الحسابات وإعداد الاشتراكات إلى ما بعد التطوير. لذلك لا يُطلب منه أي سر أو حساب أثناء التنفيذ، ولا تتفعّل خدمة أو عملية شراء تلقائيًا. المنصتان Android وiOS مجهزتان بالمصدر، وتبقى الحسابات والمنتجات والتحقق الحي خطوات النهاية.

## الواجهة

مدخلان «المساعد» و«باكج حق» في المزيد، بهوية حق الحالية وترويسة مصورة وبطاقات عاجية/داكنة. لا تعديل بصري للرئيسية أو القرآن أو المشغل. المرجعR094/R102/R190 يثبت بوابة الحساب والاشتراك والخطأ فقط؛ شاشة السؤال امتداد وظيفي لحق، لا محادثة ناجحة منسوبة إلى أذكاري.

الضيف يرى الدخول دون سعر أو نصوص حساب آخر. عدم إعداد الخدمة يظهر «غير متاح» وإعادة المحاولة. الباكج يعرض السعر والعنوان والوصف من تفاصيل المنتج التي يرجعها المتجر؛ لا5$ ثابتة أو عملة/شراء وهمي. سياسة الاستخدام25 سؤالًا/شهر خدمة و3/يوم، مستقلة عن دورة تجديد المتجر، مع رصيد من الخادم. تظهر الشروط والخصوصية من روابط HTTPS التي ستُجهّز عند الإطلاق، ولا يتيح الباك عرض منتج للبيع قبل وجود الرابطين وإعداد المزود والمتجر.

الشراء المعلق والإلغاء والخطأ والاستعادة حالات مستقلة؛ native purchased لا يمنح صلاحية بذاته. الخادم يتحقق من الشراء وربطه بحساب حق ثم يُستكمل في المتجر. الاستعادة تعيد التحقق نفسه. SDK المشترك يبدأ الاستماع مع Home ويبقى بعد إغلاق صفحة المساعد حتى لا تضيع عملية شراء جارية؛ لا يستدعي نموذجًا ولا يفتح شراءً عند بداية التطبيق. المنصة غير المدعومة لا تطلب متجرًا. إدارة الاشتراك تفتح صفحة Google/Apple الرسمية. نص حذف الحساب يوضح أن الحذف لا يلغي التجديد من المتجر.

السؤال حتى600 محرف، بموافقة واضحة على معالجته خارجيًا وتجنب المعلومات الشخصية. الشرح الآلي منفصل عن النص الأصلي ومصدره، مع تنبيه أنه قد يخطئ وليس فتوى. كل سؤال مستقل ولا يرسل تاريخ المحادثة للمعالجة. السجل خاص بالحساب وصفحاته20 عنصرًا، ويمكن حذف النص والجواب دون إعادة رصيد الاستهلاك. يُغلق أي نموذج/حوار خاص عند تبديل الحساب أو الرمز.

## فقد الاتصال والتخزين

UUID والسؤال يكتبان في FlutterSecureStorage قبل HTTP، بمفتاح assistant.pending.v1.<scope>. فشل الكتابة يمنع إرسال طلب مدفوع. عند فقد الرد تبقى الهوية وتُقرأ حالة الإيصال أولًا؛404 فقط يسمح بإعادة POST بالهوية نفسها. لا retry تلقائي لنموذج مدفوع. فشل مسح المسودة بعد الجواب يبقي الهوية حتى التحقق مجددًا دون توليد ثانٍ.

يمكن إيقاف إعادة المحاولة المحلية بعد تحذير صريح؛ لا يسحب ذلك عملية ربما التزمها الخادم ولا يعيد الرصيد، ثم يعيد تحميل الحالة والسجل. هذا يسمح بتعديل سؤال رفضته الخدمة دون قفل الحقل للأبد. الردود القديمة للحساب أو السجل لا تمسح جوابًا أحدث أو تمنح الحساب الجديد صلاحية. انتهاء401 يحتفظ بمسودة النطاق الخاص لتجديد الدخول، دون عرضها للضيف.

النسخ المحلية لا تشمل مفاتيح API أو إثباتات متجر أو مسودة الإرسال الآمنة أو أرصدة أو سجل استحقاق. الاشتراك والسجل والإيصالات مصدرها الخادم، وحذف حساب يزيل بياناته الخاصة ويبقي مجاميع التكلفة لحماية السقف العام.
