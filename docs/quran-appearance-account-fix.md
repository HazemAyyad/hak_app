# P20 — خطوط القرآن والتجويد ومسار إنشاء الحساب — 2026-10-27

أضيفت خمسة خيارات فعلية لخط نص القرآن: أميري قرآن (الافتراضي السابق)، عثماني حفص V3.0، نسخ شهرزاد، نسخ نوتو، ولطيف. ملفات الخطوط الأربعة الجديدة مرفقة دون تعديل مع رخصها؛ docs/quran-fonts.json يوثق المصدر والمراجعة والبصمة. أداة tool/check_quran_fonts.py تفحص بصمات الملفات وتغطية cmap لكل الحروف والعلامات في 6236 آية من النص المعتمد (68 محرفًا غير فارغ): لا محارف مفقودة في الخطوط الخمسة. هذا فحص تغطية محارف وليس مراجعة بشرية لكل آية أو إثبات تشكيل على كل منصة.

الاختيار يغيّر البسملة ونص الآيات في وضعي النص المتصل وآية بآية، مع معاينة فورية في إعدادات القراءة، دون تحويل النص المعتمد أو استبدال حروفه. صفحات المصحف الثابتة تحتفظ بخط الصفحة وتوزيعها الأصلي، لذا يُعطّل اختيار خط النص أثناء هذا الوضع مع شرح السبب. لم يُضف خط IndoPak مع نص غير مطابق له. الاسم المزخرف للسورة وخط واجهة التطبيق والتنقل تبقى كما كانت.

مفتاح «إظهار ألوان التجويد» يتحكم بألوان صفحات QCF V4 الداعمة. إيقافه يلوّن حبر الحروف فقط بلون واحد بعد الرسم بواسطة ColorFiltered، دون تعديل الخط أو النص أو مواضع الآيات أو خلفية التحديد. الصور الأصلية SVG غير الملونة لا تكتسب ألوانًا جديدة؛ النص المتصل يبقى كما كان. الافتراضي true يحفظ السلوك السابق. اختبار صورة بخط V4 الحقيقي المخزن محليًا يؤكد وجود ألوان في حالة التفعيل وانعدام البكسلات الملونة عند الإخفاء، واختبار منفصل يحافظ على نقر الآيات. اختبار V4 يتخطى نفسه في بيئة لا تتوفر فيها عينة build/quran-fixtures/v4-p2.ttf؛ كانت متوفرة ونُفذ هنا.

الخط والتجويد محفوظان في حالة القراءة، ومعزولان بين الضيف والحسابات، وداخل مزامنة تفضيلات القرآن والنسخ الاحتياطي والاستعادة. ملفات النسخ والتفضيلات القديمة ذات mode/fontSize/paper تبقى مقبولة مع الافتراضيات السابقة. عقد Laravel يقبل font الاختياري من المعرّفات الخمسة وtajweed الاختياري كقيمة منطقية، ويرفض القيم غير الصالحة. لا migration أو تغيير مخطط.

## تشخيص التسجيل بالبريد

الفحص الحي للقراءة فقط أعاد 404 HTML عند /api/v1/religious/account/capabilities و/api/v1/quran/manifest، بينما /public/api/v1/religious/account/capabilities أعاد 200 JSON. طلب GET إلى /public/api/v1/religious/account/register أعاد 405 JSON مع Allow: POST، ما يثبت وجود المسار دون إنشاء حساب أو إرسال كلمة مرور. Google=false وrecovery=false يعكسان إعدادات مؤجلة؛ البريد وكلمة المرور لا يتطلبان Google.

عُدّل الافتراضي المحلي HAQ_API_BASE_URL إلى https://hak.dr-bike.shop/public/api، متوافقًا مع نشر الاستضافة الحالي. يظل dart-define قادرًا على تجاوزه. الحل الدائم للاستضافة هو Document Root إلى Laravel public ثم العودة إلى العنوان النظيف /api في إعداد البناء. لم يُعدّل Document Root أو كود الخادم أو قاعدة بياناته، ولم يُنشأ حساب فعلي. إذا كانت نسخة البناء تستخدم override فيجب مراجعته أيضًا؛ تغيير المصدر لا يحدّث التطبيق المثبت تلقائيًا.
