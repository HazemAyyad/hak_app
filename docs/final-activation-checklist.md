# متطلبات التفعيل النهائية — بعد التطوير

هذه قائمة واحدة بما طلب المستخدم تأجيله إلى نهاية التطوير. لا حاجة لإرسال مفاتيح أو ملفات سرية داخل المحادثة. تجهيزها يتم في حسابات مالك التطبيق وعلى بيئة Staging أولًا، وتُحفظ الأسرار خارج Git وFlutter وpublic. لم ننشئ حسابًا أو منتجًا أو اشتراكًا، ولم نُشغّل التطبيق أو نبنِ APK أو ننشر أو نعدّل قاعدة فعلية.

## ترتيب التفعيل

1. تثبيت نسخ المصدر والاعتمادات، ثم نسخة احتياطية قابلة للتحقق من قاعدة البيانات وstorage/catalog والوسائط، مع حفظ.env ومفاتيح التشفير والتوقيع. فحص حالة المهاجرات أولًا؛ لا migrate:fresh ولا تشغيل تراكم مهاجرات الجمعية دفعة واحدة.
2. نشر الباك علىStaging دون تفعيل الخدمات، ومراجعة كل migration ديني مفقود حسب الترتيب أدناه. لا إعادة إنشاء جدول موجود. عرض التطبيق القديم والمحفوظات والتنزيلات قبل التفعيل وبعده.
3. فحص endpoints القرآن/المحتوى/الحساب والمزامنة علىHTTPS، وضبط التخزين العام والجدولة، ثم محتوى المجتمع المعتمد. RELIGIOUS_MODULE_SYNC_ENABLED وRELIGIOUS_COMMUNITY_ENABLED لا تُفعّلان قبل تحقق مخططهما والعقد الحقيقي.
4. إعدادOAuth والبريد وتجربتهما بحسابين وضيف، واسترداد ثم تجديد/إنهاء الجلسة، وحذف حساب اختبار دون مس بيانات آخر. اختيار/حفظ ملف النسخة من واجهة النظام وفشل/إلغاء الاستعادة على جهاز.
5. إعداد منتجات المتاجر فيStaging والسماح بالشراء التجريبي هناك فقط. Apple environment=Sandbox وALLOW_SANDBOX لـGoogle عند الحاجة؛ الإنتاجProduction ورفضsandbox. فحص شراء/معلق/إلغاء/فشل شبكة/استعادة/تجديد/انتهاء/استرداد/اشتراك بديل وربط حسابين، ووصولwebhook الموقّع وتكراره. لا تحويل راية محلية إلى اشتراك.
6. مراجعة سعر الموديل الفعلي وصيغةtoken counting والاستخدام والفاتورة. السقف المصدر20$، والمتاح للحجز18$ مع2$هامش؛25طلبًا×1000مشترك عند الحدود الحالية تعطي15$ حسابيًا فقط. تجربة عدد محدود من الأسئلة العربية والمراجع والرفض ومحاولات تغيير التعليمات، مع مقارنة الاستخدام الفعلي بالحجز ومراجعة أيuncertain؛ لا تصفير حجز مجهول دون دليل.
7. بعد نجاح الخدمات، تحديد موعد منفصل لبناء المنصات وفحص الأجهزة. يشملiOS علىmacOS ودمج إضافات الشراء/الفيديو وSwift؛ source/analyze وXML/plist لا تعوّض البناء. يبقى طلب المستخدم الحالي بعدمRun/APK ساريًا.
8. عند اعتماد الإطلاق: تفعيل قدرات تدريجيًا ومراقبة الأخطاء والمزامنة والوسائط والتكلفة. الرجوع يبدأ بإيقافالقدرة/كودمتوافق، لا حذف جداول مستخدمين أو إسقاط إيصالات أو حذف ملفات تلقائيًا.
