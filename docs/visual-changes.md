# سجل التغييرات البصرية

## القاعدة

الرئيسية الحالية محمية. القرآن وقارئه ومشغله والتنزيلات وتفاصيل المحتوى وشاشات البدء والمظهر تحتفظ بتصاميمها الحالية. استبدال غير محسوم يحتاج مقارنة وقرار المستخدم؛ ربط وظيفة قائمة لا يستدعي إعادة رسم الشاشة.

## P00

لا إعادة تصميم. أُضيفت طبقة Material شفافة لبطاقة إعدادات الخط حتى تظهر تأثيرات الضغط ويجتاز ListTile تحقق Flutter الحالي. الأبعاد والألوان كما هي.

## P01

- المزيد: الترويسة المصورة والبطاقات الأفقية الست من المرجع المختار، وقائمة بقية الخدمات الثلاثين دون فقد مداخل موجودة. الصور من حزمة حق المعتمدة ومكتبتها القائمة؛ الواجهة عناصر Flutter حقيقية.
- بقي شريط التبويبات بهويته الحالية، وربطنا مداخله بمسارات مستقلة. الأذكار والقبلة لهما صفحات دخول صريحة حتى اكتمال مرحلتي P03 وP09.
- الرئيسية: نفس PNG بكسلًا ببكسل في الوضعين عند412×1900. التغيير الوحيد في البطاقة هو وظيفة زر «عرض الأذكار».
- القرآن والمحتوى الديني: لا تغيير للترويسات أو القارئ أو التفاصيل؛ تغيّرت إدارة الرجوع فقط.
- لا تغيير للثيم العام أو الخط الافتراضي أو ملفات الخطوط أو صور الرئيسية.

لقطات P01 من Flutter Widget Tests عند426×922 في `build/navigation-preview`؛ ليست لقطات هاتف أو إثبات تشغيل GPS أو صوت أصلي على جهاز.
