# حالة تنفيذ قسم القرآن الكريم

بدأت الدفعة الأولى في 12 أكتوبر 2026. بقي شريط التنقل الأساسي كما هو: الرئيسية، القرآن، الأذكار، القبلة، المزيد. أضيف ربط وجهة القرآن الحالية، مع الاحتفاظ بالمسار عند التبديل إلى تبويب آخر. ملء الشاشة يخفي الشريط مؤقتًا ثم يعيده دون تعديل شكله.

شغل القرآن معزول في الفرع `codex/quran-first-batch` انطلاقًا من `6d9dd2f`. تعديلات الرئيسية والخطوط التي تُنفذ بالتزامن في شات آخر ليست ضمن هذا الفرع، ويحتاج دمجها لاحقًا إلى الحفاظ على ربط القرآن في `main.dart` و`settings_pages.dart` واعتمادياته وأصوله.

## الوظائف المنفذة

- بيانات محلية كاملة من Tanzil: 114 سورة و6236 آية و30 جزءًا وفهرسة 604 صفحات المدينة، مع الاحتفاظ بالنص الأصلي وإشعار الحقوق ومصدره.
- مدخل القرآن، قائمة السور، تصفية السور المكية والمدنية والفرز والبحث بأسمائها وحفظ السور.
- قائمة الأجزاء وصفحة تفاصيل الجزء وربطه ببدايته ونهايته الصحيحتين؛ مثال بداية الجزء السابع `5:82`.
- القراءة المستمرة وآية بآية، واختيار السورة والجزء والآية، والتكبير بملء الشاشة.
- حفظ موضع القراءة محليًا واستعادته بعد إعادة فتح التطبيق، وربط بطاقة المتابعة في الرئيسية.
- المفضلة والعلامات كقائمتين منفصلتين، وفتح الآية منهما وحذف الحفظ والفرز والتصفية.
- بحث نص الآيات محليًا، وتصفية بسورة أو جزء، والرجوع إلى النتائج مع الاحتفاظ بالحالة. يُستخدم نص Tanzil الإملائي المفصول للفهرسة دون تغيير الرسم العثماني المعروض.
- نسخ الآية ومشاركتها مع مرجعها ومصدر النص.
- إعدادات فعلية لحجم نص القرآن وطريقة القراءة ولون الورق، وربط مدخل إعدادات القرآن الموجود بهذه الإعدادات.
- خدمات Laravel عامة تعتمد على ملفات الإصدار نفسه، دون إضافة جداول أو تنفيذ migrations أو استخدام بيانات الموظفين.

## الوظائف الباقية من الخطة

- صفحات المصحف ذات السطور والتوزيع الثابت وتحديد الآية عليها. رقم الصفحة الحالي مستخرج من فهرسة المصدر، وليس إثباتًا لتنفيذ عرض صفحة المصحف.
- التفسير ومعاني الكلمات ومراجعهما المعتمدة.
- كتالوج التلاوات والمشغّل والخلفية والتكرار والسرعة والتنزيل وإدارة المساحة.
- الحساب الديني ومزامنة القراءة والمحفوظات وسياسة الدمج.
- المكوّنات الإضافية في صورة مدخل القرآن، مثل المواقيت والمقالات والصوتيات، تحتاج مصادرها ووحداتها الفعلية.
- المطابقة البصرية النهائية لكل الصور الـ24 واعتماد الخلفيات والخطوط والزخارف. الخلفيات المستخدمة مشتقة من صور المرجع بأداة الصور؛ لا تمثل اعتماد مطابقة بنسبة 100%.

## حدود التحقق

نجحت اختبارات Flutter الـ11 والتحليل دون ملاحظات، ونجحت اختبارات Laravel الستة بـ97 تحققًا، واكتمل بناء APK Debug. بيانات القرآن في Flutter وLaravel متطابقة عبر SHA256. تعذّر إثبات التشغيل على المحاكي المتاح بسبب غياب تسريع المعالج في BIOS؛ لا يُعد بناء APK اختبار تشغيل جهاز.

تُتحقق صحة النص والفهارس والعقد بالاختبارات الآلية، وتُصدّر صور الواجهات من اختبار Flutter للمراجعة البصرية. هذه الصور لا تُعتمد تلقائيًا كخط أساس للتصميم. بناء Android هو فحص تجميع مستقل عن اختبار تشغيل هاتف فعلي. لم تُنفذ اختبارات تشغيل iOS.

تصدير الصور يحمّل Cairo أيضًا بأسماء خطوط الاختبار العامة لإظهار العربية بدل مربعات الخط التجريبي؛ لا يغيّر ذلك إعدادات خطوط التطبيق أو شريطه في الإنتاج. يبقى إثبات خطوط الجهاز ضمن المراجعة على الهاتف.

يستخدم بناء Android نسخة NDK المكتملة الموجودة أصلًا في المشروع `27.0.12077973` لكل وحدات المكتبات أيضًا. يبقى تحذير Flutter بأن `jni` يطلب `28.2.13676358`؛ نسخة 28 الموجودة محليًا ناقصة، وقد نجح التجميع بالنسخة 27. يُعاد اختبار هذه الاعتمادية مع NDK 28 المكتملة في بيئة البناء ومع تشغيل المشاركة على هاتف فعلي.

## إعادة التحقق

```powershell
flutter analyze --no-pub
flutter test --no-pub
$env:QURAN_CAPTURE_DIR = Join-Path (Get-Location) 'build\quran-preview'
flutter test --no-pub test\quran_test.dart
flutter build apk --debug --no-pub
```

صور المراجعة وAPK داخل `build/` ولا تُرفع إلى Git. لا تُحوّل صور المراجعة إلى goldens معتمدة قبل مراجعة التصميم.

مصادر البناء وإشعارات حقوقها محفوظة في `tool/quran_sources/`. لإعادة إنتاج البيانات المتطابقة في التطبيق والباك:

تمنع `.gitattributes` تحويل نهايات أسطر المصادر والتراخيص الأصلية. يبني السكربت JSON بترميز UTF-8 ونهاية سطر LF صراحة، لتبقى بصمة البيانات ثابتة بين Windows وLinux.

```powershell
python tool/build_quran_data.py --source-dir tool/quran_sources --output assets/quran/quran.json --output F:/laragon/www/haq-foundation/resources/quran/quran.json
```

في بيئة Codex يُستخدم مسار Python المجمّع الذي يرجعه محمّل اعتماديات مساحة العمل.
