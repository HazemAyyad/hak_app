# P11 — الحلقات وادع معي والرسائل والقصص

التنفيذ في C:/flutter_projects/haq_app مع عقد مستقل في C:/laragon/www/haq-foundation. المرجع الوظيفي أقسام13–15 من توثيق أذكاري، والهوية البصرية تصاميم حق المعتمدة. لا تغيير لتصميم الرئيسية أو قارئ القرآن أو مشغله. المقارنة المرجعية لا تثبت سلوكًا لم يُشاهد: لا محادثة صوتية للحلقات ولا نصوص دينية أو أهداف تعبّدية مولّدة.

## الواجهات والسلوك

- الحلقات: بوابة حساب، قائمة منشورة وصفحات، نص موثق ومصدره، عضوية قابلة للإلغاء، الهدف الجماعي والمشاركون ومساهماتي. الضغط يزيد مساهمة واحدة بعد إيصال الخادم؛ لا زيادة جماعية تفاؤلية. يعيد الرجوع تحديث القائمة.
- ادع معي: الخلاصة وأدعيتي والتعليقات،180 محرفًا للمشاركة/التعليق، حالة بانتظار المراجعة، إعجاب محدد الحالة، نسخ/مشاركة وحذف المالك وحظر/إلغاء حظر وبلاغ مشاركة/حساب. المشاركات الجديدة لا تظهر للعموم قبل اعتماد الإدارة.
- رسائل حق: أنواع قرآن/حديث/دعاء/ذكر/تسبيح/فيديو/رابط، صفحات وفلاتر ومحفوظات. المحفوظات تُطلب من الخادم بمعرّفاتها عبر JSON ولا تُحصر في أول صفحة. الحذف المحلي يحتاج تأكيدًا؛ إخفاء الجميع يحفظ حدًا زمنيًا بمعرّف المنشور ولا يحذف محتوى الخادم أو الرسائل الجديدة لاحقًا.
- القصص: عرض ملء الشاشة وتقدّم/وقف/سابق/تالٍ/إغلاق/مشاركة؛ القصة النصية8ثوانٍ وتتوقف في الخلفية، مع احترام تقليل الحركة. الفيديو لا يبدأ قبل الضغط ولا يتقدم إلا بعد انتهائه؛ يوقف صوت المحتوى والقرآن قبل التشغيل.
- فيديو MP4 عبر video_player، وYouTube بمعرّف11 محرفًا داخل WebView موثوق مع رابط خارجي اختياري. لا تعطيل TLS، ولا تهيئة مشغّل قبل الطلب؛ غياب منصة مدعومة أو فشل المصدر يظهر صراحة. الروابط الخارجية HTTPS دون بيانات دخول.

## العزل وإعادة المحاولة

كل طلب يلتقط نطاق الحساب ورمزه. تبديل الحساب/انتهاء الجلسة يغلق النوافذ والصفحات الخاصة ويتجاهل الرد المتأخر. تبديل الفلاتر كذلك لا يقبل استبدال نتائج الاختيار الجديد برد قديم. الحساب الديني مستقل عن الموظف.

يُكتب UUID والحمولة قبل إرسال العدّ أو النشر في community.pending.v1.<scope>. إعادة المحاولة أو إعادة فتح القسم تستعمل الهوية والحمولة نفسيهما؛ لا استبدال مسودة معلقة بنص مختلف. فشل الحفظ قبل الطلب يمنع HTTP، وفشل إزالة إيصال مؤكد يبقي معرّفه للمحاولة التالية دون عدّ ثانٍ. إلغاء إعادة الإرسال يوقف المحاولة فقط؛ لا يسحب عملية ربما التزمها الخادم.

الحفظ والإخفاء والقراءة والصوت في community.local.v1.<scope>. أضيفت إلى النسخة المحلية بعد التحقق من الأنواع والحدود والملكية، دون إيصالات أو طابور إرسال أو أعداد/مشاركات خادم. النسخة لا تعيد نشر مساهمات. الإصدارات القديمة التي لا تعرف إعداد community قد ترفض أرشيفًا يتضمنه؛ لا ادعاء استيراد عكسي غير مختبر.

## الإدارة والتفعيل

تفصيل العقد والترحيل في docs/religious-community.md بمستودع Laravel. الخدمة معطلة افتراضيًا: RELIGIOUS_COMMUNITY_ENABLED=false. يلزم نشر مصدر migration المخصص بعد مراجعة ونسخ بيانات، ثم محتوى معتمد ومشرف ووسائط HTTPS وإعداد الجدولة والتفعيل. لم نعدّل .env أو قاعدة فعلية أو ننشر أي محتوى باسم المستخدم.

جدولة النشر خادمية مع الأمر religious-community:publish؛ الاستعلام العام يحترم وقت النشر والانتهاء حتى دون تشغيل الجدولة. لا دليل هنا على إعداد cron حي.

تنبيه الرسائل الحالي محلي فقط عند وصول رسالة أحدث أثناء تحديث قسم الرسائل المفتوح؛ يفحص القسم كل دقيقة وهو ظاهر وفي المقدمة، مع تفعيل المستخدم لتنبيهات الرسائل وإذن النظام. لا إذن تلقائي ولا FCM/APNs أو WebSocket أو استلام والتطبيق مغلق. زر الصوت يشرح هذه الحدود. إشعار عام دون محتوى خاص ويحترم نطاق الحساب. الدفع الخلفي بوابة عمل مستقلة قبل ادعاء المطابقة الكاملة.

## التحقق والحدود

المجموعة الكاملة النهائية290 اختبار Flutter ناجح في build/p11-final2-full.log. تحليل المشروع لا أخطاء أو تحذيرات؛4 ملاحظات منشئات سابقة فقط وخارج نطاق المرحلة.18 XML/plist سليمة، و31 تحقق جدولة JVM مع جمع المصادر الأصلية. الباك72 اختبارًا/1041 تحققًا على SQLite المعزولة. مقارنة الرئيسية قبل وبعد618×2850 أعطت0 بكسل RGB مختلف في الوضعين، في build/p11-home-comparison.json. خرج تحذير تحميل Rive الموجود سابقًا في اختبارات ويندوز رغم نجاح المجموعة؛ لا نعد هذه الفحوص دليل تشغيل الحركة الأصلية على هاتف.

اختبارات المنطق تحاكي فقد الرد بعد الالتزام، فشل الكتابة قبل/بعد الإيصال، إعادة الفتح، انتهاء الجلسة، الرد المتأخر للحساب/الفلتر، والحفظ/الحذف دون تعديل الخادم. اختبارات Widgets تفحص العدّ والتأكيد وإغلاق حوار الحساب وصيغة المراجعة والتشغيل الصريح، وجميع القوائم والقارئ بعرض320px وتكبير150% في الوضعين. صور build/p11-previews تستخدم بيانات اختبار معلنة وليست منشورات فعلية أو لقطات هاتف.

لا Flutter Run أو APK أو تثبيت أو بناء تطبيق. فحص Kotlin يجمع المصادر الحالية أمام Android/Flutter ويجري31 تحقق JVM دون Gradle. ملفات XML/plist سليمة؛ Swift ودمج إضافات الفيديو/WebView والشراء الأصلي مستقبلًا تحتاج تجميع المنصات وتجربة جهاز في P13. نجاح SQLite المعزولة لا يثبت تزامن عمليتي MySQL أو إيصال إشعار أو تشغيل فيديو على هاتف.

اعتمدت الحزم المثبتة video_player2.14.1 وwebview_flutter4.14.1 وurl_launcher6.3.2، دون تحديث الحزم القديمة. minSdk صريح24، وكان الحد الفعلي24 أصلًا من FlutterExtension المثبت؛ لا نعد هذا تجميع Android ناجحًا.

مراجع الحزم: [video_player](https://pub.dev/packages/video_player)، [webview_flutter](https://pub.dev/packages/webview_flutter)، [url_launcher](https://pub.dev/packages/url_launcher)، [YouTube IFrame API](https://developers.google.com/youtube/iframe_api_reference).
