# بداية التطبيق والرجوع

زر الرجوع في ترويسة القرآن المشتركة وترويسة الإعدادات يظهر على اليمين، والسهم يتبع RTL ويشير إلى اليمين. إجراءات ترويسة القرآن تظهر على اليسار. إغلاق وضع القراءة المكبر يظهر في بداية الشريط العربي أيضًا.

تشغيل التطبيق يمر بالترتيب:

1. شعار ثابت في شاشة تشغيل Android/iOS، حتى يصبح Flutter جاهزًا.
2. شاشة Flutter بالشعار الأصلي المتحرك عبر ملف Rive محلي.
3. ثلاث شاشات تعريفية عند غياب تفضيل إكمال التعريف.
4. الرئيسية بعد الإكمال أو التخطي.

يُحفظ الإكمال في SharedPreferences بالمفتاح `startup.onboarding.v1.completed`. لا يحفظ التفضيل عند مشاهدة أول شاشة فقط. الرجوع داخل التعريف يعود للشاشة السابقة، وبعد الإكمال لا يمكن الرجوع إلى السبلاش أو التعريف من الرئيسية. بدء التشغيل التالي يظهر السبلاش ثم الرئيسية مباشرةً.

الشاشات التعريفية تعرض القرآن والبحث وحفظ القراءة، أقسام الأذكار ومحتوى اليوم، وإعدادات المظهر والخط. لا تطلب تسجيلًا أو أذونات، ولا تعد بتلاوات أو إشعارات غير منفذة. تصميمها يدعم الوضعين والخط المختار والشاشات الضيقة؛ الرسوم الزخرفية تتدرج داخل المساحة المتاحة.

## حركة Rive

- الأصل: `assets/branding/haq_logo_transparent.png` مضمن داخل Rive دون تغيير الشعار.
- ملف التطبيق: `assets/animations/haq_splash.riv`.
- المصدر القابل للتعديل: `tool/haq_splash_rive/scene.rml` و`rive.yaml`.
- Artboard: `Haq Splash`، state machine: `Splash`، حركة `Logo entrance` بطول 144 إطارًا عند 60fps.
- الحركة: ظهور تدريجي، تكبير خفيف واستقرار، وهالة ذهبية تتسع ثم تختفي.
- لا يحتوي الملف Luau أو shaders أو سكربتات تتطلب توقيعًا أو نشرًا على حساب Rive.

لإعادة البناء من جذر المشروع:

```powershell
rive tool/haq_splash_rive --verify
rive inspect tool/haq_splash_rive --summary
rive tool/haq_splash_rive --once
Copy-Item tool/haq_splash_rive/build/haq_splash_rive.riv assets/animations/haq_splash.riv
```

تستخدم الواجهة [حزمة Rive Flutter الرسمية](https://pub.dev/packages/rive) ومصنع Flutter للرسم. يُدار الملف والـcontroller داخل شاشة السبلاش ويُتلفان عند مغادرتها. يبدأ زمن العرض بعد تحميل الملف، ويوجد مسار للشعار الثابت إذا فشل التحميل، وحماية زمنية لمنع التعليق. عند تفعيل تقليل الحركة تظهر نسخة ثابتة قصيرة.

## التحقق

`test/startup_test.dart` يحمّل ملف Rive الحقيقي ويشغّل state machine، ويفحص التشغيل الأول وإكمال الشاشات الثلاث واستعادة التفضيل بعد إعادة إنشاء التطبيق، والتخطي وتقليل الحركة، و320×568 مع خط 120%، وموضع زر الرجوع ووظيفته.

لقطات Flutter الناتجة محفوظة في `build/startup-preview/`: `splash.png` و`onboarding-1.png` و`onboarding-2.png` و`onboarding-3.png`.

اختبارات الصفحات القديمة تستخدم `HaqApp(showStartup: false, ...)` للوصول مباشرةً إلى الواجهة التي تختبرها؛ التشغيل الحقيقي يستخدم القيمة الافتراضية true، وتغطيه اختبارات البداية.

على Windows تحتاج اختبارات Rive تجهيز مكتبتها الأصلية:

```powershell
dart run rive_native:setup --platform windows --clean
flutter test --no-pub
flutter analyze --no-pub
flutter build apk --debug --no-pub
```

إذا كانت المكتبات موجودة في الكاش ولكنها لم تُنسخ إلى build للمشروع، يجبر `--clean` أداة Rive على تجهيزها ونسخها. لم يتصل هاتف Android بهذه الجلسة. تعديل بدء iOS يُراجع بنيويًا هنا؛ بناء iOS وتشغيله يحتاج macOS.
