LICENCE FOR THE BUNDLED TIME ZONE BOUNDARY DATA
===============================================

This file covers the generated data files in `lib/data/` and the derived
identifier table in `lib/src/zone_names.dart`. It does NOT cover the source
code of this package, which is licensed under the MIT License (see LICENSE).


Source
------

The bundled index is derived from the `timezones.geojson.zip` (land-only,
full-fidelity) release asset of the Timezone Boundary Builder project:

    https://github.com/evansiroky/timezone-boundary-builder

which in turn derives its boundaries from OpenStreetMap:

    https://www.openstreetmap.org

Timezone Boundary Builder's own code is MIT licensed, but the boundary data it
produces is released under the Open Database License. This package transforms
that data (quantisation, delta encoding, spatial indexing) and therefore ships
a Derivative Database within the meaning of that licence.

Note on disputed territories
----------------------------

The upstream data documents 25 pairs of time zones permitted to overlap, most
of which correspond to disputed territories. Where a coordinate falls inside
more than one zone, this package returns a single identifier chosen by an
arbitrary deterministic rule. That choice is a technical tie-break and is not a
statement about sovereignty. See the README for details.
